# Avaliacao-de-comparacao-entre-HTTP-3-e-HTTP-1.1

Este projeto propõe a realização de experimentos comparativos entre os protocolos HTTP/1.1 e HTTP/3, analisando métricas relacionadas ao desempenho da comunicação, como tempo de resposta, estabilidade da conexão, perda de pacotes e comportamento em cenários com atraso artificial e degradação de rede.

Os experimentos serão realizados utilizando Python para automação dos testes, Docker para criação do ambiente de experimentação, Caddy como servidor com suporte HTTP/3, tc/netem para simulação de condições de rede, Wireshark para análise de pacotes e Matplotlib para geração de gráficos comparativos.
